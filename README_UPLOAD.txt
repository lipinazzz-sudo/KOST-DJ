# DJ Family Kost — Website Pages

Upload the HTML files to the root of the GitHub repository.

Recommended structure:

- index.html
- aturan.html
- kunjungan.html
- pendaftaran.html
- pembayaran.html
- maintenance.html
- checkinout.html
- login.html
- portal.html
- images/
  - kamar-ganjil.jpeg
  - kamar-genap.jpeg

This package is intentionally frontend-only. Forms currently validate in the browser and show a confirmation message; no Google Sheets/API connection has been added yet.

The public Aturan page intentionally omits nominal fines. The source operational document contains fine/sanction details, but those amounts are not displayed publicly here.
